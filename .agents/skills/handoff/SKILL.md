---
name: handoff
description: 暫停、換任務或結束工作前使用：更新 PROGRESS.md 並提醒是否切換新對話。使用者說要暫停、換任務、先到這裡時也要主動使用。
---

1. 讀 `PROGRESS.md` 與 `git status`、`git log --oneline -5`。
2. 更新 `PROGRESS.md` 四個段落，保持 40 行以內：
   - **目前進度**：分支、做到哪、未 commit 的變更
   - **已做的決定**：新增這次的決定與理由（一行一個）
   - **下一步**：接手者第一件要做的事要具體到檔案或指令
   - **待辦**：完成的打勾或移除，新發現的加入
3. 有未 commit 的變更時，問使用者要 commit 還是保留。
4. 提醒使用者：「PROGRESS.md 已更新。這個任務告一段落，建議切換新對話再開始下一個。」
